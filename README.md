
# Inventory Management System

A web-based Inventory Management System developed using HTML, CSS, JavaScript, PHP and MySQL.

## Features
- Admin dashboard
- Add new products
- Upload product pictures
- View product catalogue
- Edit product information
- Delete products
- Search products
- Low stock notifications
- Automatic inventory calculations

## Technologies Used
- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP

## Installation

1. Install XAMPP.
2. Copy the project folder into htdocs.
3. Start Apache and MySQL.
4. Open phpMyAdmin.
5. Create a database named inventory_db.
6. Import the database SQL file.
7. Open http://localhost/inventory_system/
